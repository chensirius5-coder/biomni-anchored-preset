# Changelog

## 1.0.0 — 2026-08-15

- Initial public project layout.
- Added the full `Biomni (Anchored)` preset copied from the local
  `anchored-standard` installation.
- Added six bridge tools: `biomni_status`, `biomni_tools`, `biomni_run`,
  `biomni_know_how`, `biomni_data`, `biomni_python`.
- Added `residentTools` support to `tool-bootstrap.mjs`.
- Bundled `biomni-local-engine` and `neonatal-cardiac-regeneration` skills.
- Added install/uninstall scripts, syntax checks, unit tests, and GitHub
  Actions CI.
